## Per-Batch Folder Contents

Each `BatchNN/` folder contains:

- `CPP102_Week3_Assessment_BatchNN.docx` — student-facing assessment sheet (10 problems across 3 levels, submission and Git instructions, rubric).
- `CPP102_Week3_Answer_Key_BatchNN.docx` — **instructor use only**, suggested IPO tables, algorithms, pseudocode, and Mermaid flowcharts for all 10 problems. Do not distribute to students.

All six batches measure the same intended learning outcomes, contain the same number and difficulty of problems, and are graded with the same rubric. Only wording, context, numbers, and variable names differ, to keep the batches fair while reducing copying.
