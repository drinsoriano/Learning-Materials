# Week 04 – CPP102

## Topic

Variable Declaration, Data Types, Comments, Type Conversion, and Operators in Python

Week 4 builds directly on the algorithm, pseudocode, flowchart, and Git/GitHub foundation from Weeks 1–2 (assessed in Week 3) by translating that program logic into real Python code.

## Intended Learning Outcomes

By the end of the lesson, the students should be able to:

1. Declare and initialize Python variables using valid identifiers and appropriate data types.
2. Apply type conversion and arithmetic, comparison, logical, and assignment operators in Python expressions.
3. Develop, test, and submit a simple Python program that accepts user input, performs calculations, displays formatted output, and uses the prescribed Git and GitHub workflow.

## Laboratory Activity

**Week 4 Laboratory Activity: Student Daily Expense Calculator** — an individual, sequential-code-only Python program (no `if`/`elif`/`else`, loops, functions, lists, or dictionaries) that asks for a student's full name, daily allowance, transportation expense, food expense, other expenses, and number of school days, then calculates and displays total daily expenses, remaining daily allowance, total allowance for the given school days, projected total expenses, projected remaining allowance, and two Boolean results (within daily allowance, and projected remaining allowance greater than zero).

## Git and GitHub Workflow Summary

Git and GitHub were introduced in Weeks 1–2; Week 4 reinforces the same workflow:

```
git status
git add .
git commit -m "Add initial Week 4 expense calculator"
# ... continue developing and testing ...
git add .
git commit -m "Complete CPP102 Week 4 laboratory activity"
git push
```

At least two meaningful commits are required. See the module document for the full troubleshooting guide (including the `index.lock` fix).

**Reminder:** Students must create and edit all files locally in VS Code and run every Git command through the terminal — not the GitHub web interface.
